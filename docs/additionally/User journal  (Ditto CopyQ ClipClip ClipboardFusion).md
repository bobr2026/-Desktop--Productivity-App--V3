### ClipClip
+
установка простая

интерфейс простой и интуитивно понятный  и не перегружен 
есть филтр по дате, типу
поиск простой 
два вида просмотра 
есть возможность делать скриншоты и запись экрана 
можно закрепить основное поверх других 
-
старый ui 
нельзя закрепить поверх других окон (отдельно список например  )
неудобно смотреть скопированные картинки картинки
